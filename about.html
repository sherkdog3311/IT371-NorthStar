About NorthStar

NorthStar Trading Card Collection & Deck Manager is a website designed to help Magic: The Gathering players and collectors organize their cards and decks in one location.

The goal of NorthStar is to make managing a growing card collection easier while providing useful tools for browsing cards, building decks, and planning future additions.

Project Goals

Organization

Provide a simple way to organize cards by important information such as set, type, color, rarity, condition, and quantity.

Deck Management

Connect cards from a personal collection to deck lists so players can keep track of where their cards are currently being used.

Easy Navigation

Maintain a clear and consistent navigation system that allows users to quickly move between the major areas of NorthStar.

Responsive Design

Create a layout that remains readable and useful across desktop computers, tablets, and mobile devices.

Website Design

NorthStar uses a dark visual theme with bright blue branding and green accents to create clear contrast between navigation, headings, and page content. Consistent fonts, colors, spacing, and page layouts are used throughout the website.

Responsive CSS allows page elements to adjust when the site is viewed on smaller screens. Content grids change from multiple columns to a single-column layout, while the navigation menu reorganizes to make better use of the available screen space.

Future Development

Collections and decks currently save in the same browser on the same device, with downloadable backups. User accounts, synchronized storage, and interactive wishlist entries remain planned improvements. Future versions of NorthStar could also include features such as card recommendations, deck statistics, mana curve analysis, price tracking, and other tools that help players manage both their collections and decks.
