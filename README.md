# NorthStar M6.4

Trading Card Collection & Deck Manager by Jesse Sherk.

Hosted site: https://sherkdog3311.github.io/IT371-NorthStar/

Module 6 adds contact.html and contact.js. The form submits name, email,
and message to Formspree with POST. A successful service response triggers
an inline confirmation; unsuccessful requests preserve the entered data.
With JavaScript disabled, the regular HTML form submits directly to Formspree.
The Module 5 card filters remain in script.js.

Upload the files inside this folder to the GitHub repository root.
Before submitting the assignment, test the hosted Contact page and verify
that the test message appears in Formspree Submissions. Validate all seven
hosted HTML pages at https://validator.w3.org/ and check mobile layout.
Local response-handling tests passed for acceptance, rejection, connection
failure, and invalid input. Live submission and W3C validation still require
verification after upload.
